# Plan — design, cursor, Photo workspace, Image upgrades (2026-11-12)

Owner request: (1) a Lightroom-style photo editor that makes RAW pictures look professional, without the rarely used extras; (2) more Photoshop/GIMP functionality in the paint editor; (3) a considered redesign, because the current look reads as a cheap Windows XP knockoff (colours, hard angles); (4) a Windows XP-style mouse cursor.

Execution order: design and cursor first, because every later screen uses them; then the Photo workspace; then the Image upgrades. Each phase ends with unit tests, real-Chrome browser tests, screenshots I inspect, a commit and a push to `main`.

## Phase A — Design system and XP-style cursor (items 3, 4) — superseded by D24

**Diagnosis.** The current chrome mixes saturated XP blue bars, beige panels, bevel gradients and square corners. The workspaces (CAD's pale-blue canvas, Image's grey stage) don't share a palette with the chrome. Everything has the same visual weight, so nothing reads as primary.

**Direction: a neutral, dark "studio" interface, the convention of professional creative tools** (Lightroom, Affinity, Blender, Figma's editor). The reasons are practical, not fashion:

- Neutral dark grey around a photo or painting doesn't bias colour judgement, and the artwork is the brightest thing on screen.
- One restrained accent colour, used only for state (active tool, selection, focus, primary button), tells the user what is active at a glance.
- Hierarchy comes from spacing, type weight and three surface levels instead of borders and gradients.

**Tokens** (one CSS custom-property set in `src/shared/theme.css`, used by every stylesheet):

- *Surfaces:* app `#16171a`, panel `#1e1f23`, raised `#26282d`, control `#2d2f35`, hover `#363941`, canvas well `#111214`.
- *Text:* primary `#e8e9ec`, secondary `#a3a7b0`, muted `#6d717b`.
- *Lines:* `#2f3137` hairline, `#3b3e46` control border.
- *Accent:* `#4f8cff` (hover `#6a9dff`, subtle `#4f8cff26`). Status colours: success `#3fb68b`, warning `#e0a43b`, danger `#ef5d5d`.
- *Type:* Inter, Segoe UI Variable, SF Pro, system-ui stack. 12.5 px UI text and 11 px uppercase section labels with letter-spacing; tabular numbers for values.
- *Shape:* 6 px control radius, 10 px floating panels, 8 px spacing grid. Focus is a 2 px accent ring.
- *Motion:* 120 ms ease-out on hover and menus only.

**Layout.**
- A 44 px top bar: app mark, then document title and dirty dot, with a segmented workspace switcher (CAD · Image · Photo · Video) centred.
- A 36 px command row: menus at left, labelled contextual actions at right.
- A 44 px icon tool rail with an active pill.
- A 300 px right inspector with collapsible sections.
- A 24 px status bar.
- Canvases sit in a recessed well. Menus and dialogs float with soft shadows.
- CAD sketch and 3D views move to a dark blueprint palette, so CAD matches the rest of the app.

**XP-style cursor (item 4).** Original SVG cursors drawn in the XP visual language: white arrow with a black outline and a soft drop shadow, a link hand, a text I-beam, a crosshair, a move cross, resize arrows and a busy hourglass. They are applied globally through CSS `cursor:url(...)` with hotspots, and tools set the matching one. These are new drawings, not Microsoft's bitmaps (licence rule in [DECISIONS.md](DECISIONS.md)).

**Verification.** Update the S10/S09 tests for intentional changes, inspect screenshots of all workspaces at 1280 × 720 and 390 × 844, and run a contrast check (text ≥ 4.5:1 on its surface).

## Phase B — Photo workspace (item 1)

**Decoder.** `libraw-wasm` 1.6.0 (ISC wrapper; LibRaw is LGPL-2.1/CDDL-1.0 dual-licensed and used unmodified) runs in its own worker. It reads CR2/CR3/NEF/ARW/DNG/RAF/ORF/RW2 and returns 16-bit **linear** sRGB (gamma 1/1, camera white balance, no auto-brightening). JPEG, PNG, WebP and HEIC (where the browser supports it) decode through the browser and are linearized. The original file bytes are stored in the `.gsnv-photo` project, so edits stay non-destructive.

**Develop pipeline** (pure CORE, Float32 linear light, the same code for preview and export, run in a worker on a screen-sized proxy while editing and at full resolution for export). The stages run in this order:

1. White balance: temperature and tint relative to as-shot, applied as per-channel gains.
2. Exposure (EV).
3. Tone:
   - Contrast, Highlights, Shadows, Whites and Blacks act on perceptual luminance through smooth masks.
   - A base "camera" tone curve with a filmic highlight shoulder, so RAW files don't look flat (this is most of the "professional" look).
4. Presence: Texture and Clarity (local contrast at two radii), Dehaze (local contrast plus black-point lift compensation), Vibrance (protects already-saturated colours and skin) and Saturation.
5. Parametric tone curve: Highlights, Lights, Darks and Shadows regions.
6. Colour mixer: hue, saturation and luminance for 8 colour bands with smooth band weights.
7. Detail: sharpening (amount, radius, masking), luminance and colour noise reduction.
8. Effects: post-crop vignette (amount, midpoint), grain.
9. Geometry: crop rectangle with aspect presets, straighten angle, 90° rotations and flip.

**Tools around the pipeline.**
- Live RGB histogram with clipping warnings.
- Auto (exposure, whites/blacks and vibrance from histogram percentiles).
- Before/after (`\`), and double-click to reset any slider.
- Presets: Natural, Vivid, Portrait, Landscape, Black & White, Film Warm, Matte, High Key.
- Copy and paste settings.
- Export JPEG (quality) or PNG at full or long-edge-limited size.
- Each slider release is one history entry. Undo, recovery and save/open work like the other workspaces.

**Verification.**
- Golden pipeline unit tests for neutral identity, exposure ±1 EV, white-balance direction, monotone tone curves, vibrance protecting saturated colour, crop geometry and histogram counts.
- A real LibRaw decode of the Canon 5D Mark III DNG (CC0, raw.pixls.us) in Chrome.
- A browser test: open RAW, apply Auto and a preset, change sliders, undo, save/open the project and export a JPEG of the right size.
- Before/after screenshots, inspected.

## Phase C — Image workspace upgrades (item 2)

- **Layers:** add, duplicate, delete, rename, reorder, visibility, opacity, blend mode (normal, multiply, screen, overlay, darken, lighten, difference), merge down and flatten, with a Layers panel showing thumbnails. Old single-layer projects still open.
- **Selection becomes a mask:** rectangle, ellipse, lasso and magic wand (tolerance, contiguous); add/subtract with Shift/Alt; select all/none/invert. Painting and filters are clipped to the selection.
- **Brush engine:** soft round brush with size, hardness, opacity and flow, antialiased and pressure-aware. Pencil stays hard.
- **New tools:** gradient (linear/radial, foreground→background or →transparent), airbrush/spray, clone stamp (Alt-click source), smudge, blur/sharpen brush, rounded rectangle.
- **Adjustments** (with live preview dialogs): Brightness/Contrast, Hue/Saturation/Lightness, Levels, Curves (input/output points), Colour balance, Desaturate, Invert, Posterize, Threshold.
- **Filters:** Gaussian blur, Unsharp mask, Add noise, Pixelate, Find edges, Emboss.
- Export keeps PNG (flattened). Project files store each layer as a tiled asset.

**Verification.** Unit tests for blend modes (golden pixels), mask operations, wand flood, gradient endpoints, brush hardness falloff, every adjustment's identity and known values, and the layered project round trip. A browser test drives layers, selection-clipped painting, an adjustment, a filter, undo and save/open.

## Out of scope for this pass

Video, Lightroom catalogue/library management, local masking brushes in Photo, lens-profile corrections, HDR/panorama merge, text layers that stay editable, and Photoshop PSD import/export.

## Scope additions, second round (owner, 2026-11-12)

The owner asked for the following. All of it keeps the current XP design (DESIGN-XP.md, D24). It is listed in the order it will be built: quick wins first, with a push at each checkpoint.

**Done in this round**
- SEO: descriptive title and description, social tags, structured data, favicon, robots.txt, and plain wording without em dashes.
- Link preview: `public/og-image.png` (1200 × 630, XP window with a screenshot). Set `SITE_URL` in the Cloudflare build so `og:image` is absolute.
- A small white Goosnav mark in the title bar (from the official logo-icon in goosnav-labs-hq).
- File menu: New always makes a new document. Projects autosave to File > Recent (browser storage, newest 12). Replacing a document never prompts, and a pending recovery never blocks New. File > Rename.

**Next, in order**
1. Image text and transforms: multi-line text with font, size, bold, italic and alignment, placed on its own layer and movable right away; a free transform (scale and rotate by any angle) for the selection or layer with live preview; arrow-key nudging.
2. CAD:
   - Unit defaults: choose metric (mm) or imperial (inch) for new parts.
   - Cut (pocket) extrusions, through all or by depth.
   - Fillets (rounded edges) and chamfers on the solid's edges.
   - Better constraints: equal, parallel, perpendicular, coincident and fixed points, with clearer messages when a sketch is over-constrained.
3. Video (basic editor): import clips, a timeline with trim and split, ordering, titles, fade in and out, and WebM/MP4 export using the browser's encoders.
4. Document (basic Word-style editor): headings, paragraphs, bold, italic, underline, lists, alignment, images and page setup, exported to PDF. ShareLaTeX/Overleaf is not needed for this level; a browser print-to-PDF path or a small PDF writer is enough.
5. Slides (basic PowerPoint-style editor): a slide list, text boxes, images, simple shapes, themes in the XP style, presenting full screen, and export to PDF.
6. Audio (bare-bones editor): import a file, see the waveform, select, cut/copy/paste/delete, fade, normalize, change volume, and export WAV.

New workspaces (Document, Slides, Audio) join the existing four as taskbar buttons. Each reuses the shell's history, Recent, recovery and file handling.
